# IT_Expenditure_Analysis

Analyze the IT expenditure for a company
The organization is facing challenges in effectively managing its IT expenditure, as evidenced by significant variances between actual spending and both planned and forecasted budgets. 
There is a critical need to understand where these discrepancies are occurring (by month, business area, country, cost element, and IT area), why they are happening, and to gain better control over future IT financial performance.
